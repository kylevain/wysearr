SUPERSEDED ARCHITECTURE NOTE

The former "Wyse 3040 Torrent Downloader" document described a different host,
external USB storage, a qBittorrent watch-folder workflow, and a shell importer.
It is retained only to explain old watch/, active/, complete/, and
processed-torrents/ directories.

The production host is the Dell Wyse 5010 named wysearr. The authoritative
architecture is docs/architecture.md. qBittorrent now uses media categories;
Huey, the ARR applications, and BookBot provide deterministic acquisition and
import. The old watched-folder workflow is disabled and must not be redeployed.
