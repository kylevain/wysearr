Project: Wyse 3040 Torrent Downloader

Purpose:
- Dedicated torrent appliance.
- No media libraries.
- No additional services.

Hardware:
- Dell Wyse 3040
- Internal eMMC:
    - Debian
    - qBittorrent-nox
    - Web UI
    - watch folder

- External 2TB USB SSD:
    - active/
    - complete/
    - processed-torrents/

Pi4:
- Hosts Kavita
- Hosts Audiobookshelf
- Hosts RomM
- Hosts DAS storage
- Hosts SnapRAID

Storage Philosophy:
- Temporary torrent storage remains on Wyse SSD.
- Permanent media storage remains on DAS.
- Original torrent payloads are disposable.
- No SnapRAID protection required for torrent payloads.

Workflow:

1. User drops .torrent into watch/

2. qBittorrent imports torrent

3. .torrent moved to processed-torrents/

4. Download stored in active/

5. Completed download moved to complete/

6. Torrent Importer runs automatically

7. Importer:
    - determines media type
    - cleans filenames
    - creates destination folders
    - checks for duplicates
    - copies file into library

8. Library becomes immediately available

9. Original remains in complete/ and continues seeding

10. After 14 days:
    - qBittorrent removes torrent job
    - delete original payload from complete/
    - delete matching .torrent from processed-torrents/
    - remove associated qBittorrent metadata

Result:
- Immediate library availability
- 14-day seeding
- No permanent duplicate storage
- DAS isolated from torrent activity
